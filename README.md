## Por que vale

La fecha esta cerca, pero el producto se puede reducir:

- `waibav` ejecuta tareas y produce evidencias.
- `vimport` ingiere reglas, paginas, PDFs y APIs.
- `web_project_stack` permite demo rapido.

## Producto propuesto

`Grant Scout Agent`: lee convocatorias, extrae requisitos, genera checklist,
calcula ROI y prepara paquete de submission.

## Primer sprint

1. Prototipo de ingestion de 5 convocatorias.
2. UI con ranking y checklist.
3. Integrar Google agent API como planner.
4. Video demo de 2 minutos con este mismo repo.
